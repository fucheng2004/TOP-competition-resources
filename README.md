## 📖 查阅建议

- **快速了解项目**：先阅读作品介绍或 PPT，了解项目背景、核心功能和展示内容。
- **查看实际效果**：进入包含演示视频的项目目录，观看功能演示。
- **深入了解实现**：结合设计与开发文档、技术方案、接口文档或测试报告阅读。
